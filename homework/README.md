- `homework00/` - Stage 00 environment and Jupyter check.
- `homework01/` - Stage 01 problem framing and stakeholder context.
- `homework02/` - Stage 02 tooling, configuration, and environment check.
- `homework03/` - Stage 03 NumPy and pandas data summary.
- `homework04/` - Stage 04 Yahoo Finance acquisition and web-table ingestion.
- `homework05/` - Stage 05 CSV and Parquet storage round trip.
- `homework06/` - Stage 06 preprocessing and validation.
- `homework07/` - Stage 07 outlier assumptions and sensitivity.
- `homework08/` - Stage 08 exploratory data analysis.
- `homework09/` - Stage 09 leakage-aware feature engineering.
- `homework10a/` - Stage 10a linear regression and residual diagnostics.
- `homework10b/` - Stage 10b time-aware classification pipeline.
- `homework11/` - Stage 11 bootstrap uncertainty, scenarios, and subgroup risk.
- `homework12/` - Stage 12 stakeholder-ready report and charts.
- `homework13/` - Stage 13 saved model and two-route Flask API.

Use the requirements in `homework_materials/` and commit the completed homework, not the instructor original.
