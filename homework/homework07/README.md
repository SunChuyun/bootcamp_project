# Homework 07: Outliers and Risk Assumptions

The notebook compares three treatments of extreme daily returns: all observations, IQR filtering, and 5%/95% winsorization. Reusable functions with parameter checks and docstrings are stored in `src/outliers.py`.

The sensitivity analysis reports slope, intercept, R-squared, and MAE, then documents the risk of treating genuine market shocks as data errors.
